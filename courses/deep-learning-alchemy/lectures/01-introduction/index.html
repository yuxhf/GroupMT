本节课复盘 · What you should remember

  • 课程理念：Prediction is Understanding。先提出预测，再运行实验，用结果修正自己的 world model。
  • 训练系统四要素：Data 定义输入分布；Architecture 定义参数如何映射到预测；Objective 定义误差；Optimization 决定参数如何更新。
  • 预训练目标：自回归语言模型根据前文预测下一个 token，并通过交叉熵 / 负对数似然训练。
  • 实验原则：一次改变一个因素；记录曲线和最终 Loss；比较架构时要给不同变体合理的学习率搜索。
  • 课程学习方式：Assignment 积累真实实验，Quiz 检验能否预测新实验。

建议课后自测

  1. 为什么一个架构在默认学习率下训练失败，不代表它在所有学习率下都失败？
  2. Data、Architecture、Objective、Optimization 分别控制训练系统的哪一部分？
  3. 为什么只看最终 Validation Loss 不够，还要看训练曲线和内部指标？
  4. 如果移除残差连接，你会预期训练稳定性和最终 Loss 如何变化？请说明依据和不确定性。

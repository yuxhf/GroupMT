完整步骤文字
  1. 同一医疗决策查询，先比较快路与慢路

    Figure 18 的查询希望获得值得探索的 evidence-based practices。Familiarity 只做一次 Top-10；不确定请求则进入 Recollection。

    两条路径共享同一 memory bank，差别是是否允许 query 继续演化。

    route(xₜ) ∈ {Familiarity, Recollection}
  2. Familiarity：一次 Top-10 显著但零散

    单次相似度检索首先抓住 conventional medicine 等显著词义，也可能混入 healthy recipe；它没有继续寻找跨 session 的互补证据。

    快路径成本低，但一次近邻集合可能只覆盖问题的一部分语义。

    S_fast = Top-K(sim(xₜ, zᵢ))
  3. Recollection r=0：只聚类当前局部 Top-4

    慢路径先取当前 query 的局部候选，再将这批候选临时分为不同语义簇；不是预先聚类整个 memory bank。

    局部聚类把 patient history 与 health records 等方向分开，避免平均成一个模糊 query。

    N₀=(B+0)F=4；B=2，F=2
  4. 簇中心与原查询共同生成 child queries

    每个簇中心提供新的探索方向，同时保留当前路径并加回原始查询残差；图中的 q₁、q₂ 是更新后的 branch query。

    簇中心负责扩展语义，原查询残差负责抑制 query drift。

    x_b⁽ʳ⁺¹⁾=norm(αx⁽ʳ⁾+(1−α)g_b⁽ʳ⁾+xₜ)
  5. 先给分支打分，再只保留 Top-B

    child branch 的分数是本簇 memories 对新 branch query 的相似度总和。保留分支继续展开；被裁剪方向不会向下一轮扩展。

    这里选的是值得继续搜索的方向，不是学习到的 memory helpfulness。

    S_branch(b)=Σᵢ∈G_b ⟨x_b,zᵢ⟩；Beam←Top-B
  6. r=1→2：保留分支继续检索，未见 memory 进入 Bag

    每个 active branch 独立执行 retrieve–cluster–mix；只有保留分支中的未见 ID 进入 ResultBag，重复条目被去重。

    Top-10 是跨轮累计结果，不是最后一轮一次性选出，也不是每条分支固定分配名额。

    Nᵣ=(B+r)F：6→8；Bag←unique(Bag∪kept hits)
  7. r=3：达到 K 或轮数上限，形成最终 Top-10

    慢路径逐步补齐 patient history、health records、structured methodology 等互补线索，再把 ResultBag 截取为最终上下文。

    Figure 18 展示的是一次成功重构；Figure 19 同时说明慢路径也可能漂移。

    stop if |Bag|≥K or r=r_max；K=10
